Welcome to the documentation for Simple 2D Platformer.
This project demonstrates a modular React-based platformer game, including game logic, UI components, and hooks for player interaction.

Features

  • Multiple levels with increasing difficulty
  • Collectibles and score tracking
  • Deadly obstacles and exit doors
  • Keyboard controls for player movement
  • GDPR cookie consent popup

Modules

  • Cookies – Components and hooks for cookie consent
  • Game – Core game components (Player, Obstacles, ExitDoor, etc.)
  • Hooks – Custom React hooks for game logic
  • Pages – React pages like StartPage, GamePage, SettingPage
  • SettingsForm – Settings form component
  • UI – Reusable UI components (Buttons, HUD, Modals)
